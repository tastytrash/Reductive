# Reductive

A Fabric mod that adds utility items and blocks that improve QoL, mitigate tedious farming, or are just fun, centred around refining vanilla Minecraft materials into smaller parts.

## Features

### Tools
- **Drill**: Handheld drill for faster mining, breaks blocks a wooden pickaxe/shovel can
- **Industrial Drill**: Upgraded drill that breaks in a 3x3 area
- **Chainsaw**: Cuts wood/organic blocks more efficiently, breaks anything a wooden axe/hoe can
- **Industrial Chainsaw**: Breaks multiple wood blocks at once
- **Slingshot**: Fires pebbles, dynamite, or fire charges (supports crossbow enchantments)

### Fishing
- **Tiered Fishing Rods** (Copper/Iron/Gold/Diamond/Netherite): Catch multiple items at once
- **Fishing Baits**: Special baits that change the fishing loot table
    - **Treasure Bait**: Increases treasure loot table drops
    - **Prismarine Bait**: Ocean-themed drops (prismarine, sponges, tridents)
    - **Abyssal Bait**: Cave/deep dark drops (amethyst, sculk, Swift Sneak books)

### Utility
- **Portable Crafter**: Portable crafting table
- **Matchstick**: Single-use flint and steel
- **Dynamite**: Throwable weaker TNT
- **Lapis Bottle o' Enchanting**: Throw to gain 100 XP

### Blocks
- **Experience Tank**: Stores up to 1600 XP. Use a lapis bottle to extract 100 XP, or a normal bottle for 10 XP. Standard Bottle o' Enchanting now grants 10 XP.
